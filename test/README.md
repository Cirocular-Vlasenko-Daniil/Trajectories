# Стенд

Прошивка собирается и прогоняется на хосте: `trajectories.cpp` включается в
тест целиком, а Arduino подменяется заглушками из `stub/`. В `host.cpp`
— часы, кнопки, фреймбуфер, перехват MIDI и настоящее NVS-хранилище,
поэтому проверяемы и картинка на экране, и то, что уходит в MIDI, и
сохранение патчей.

```
./run.sh poly poly2 poly3 structure meta modlayer
```

| набор | о чём |
|---|---|
| `poly` | что каждый процессор делает с аккордом; баланс Note On/Off |
| `poly2` | кто видит весь аккорд, а кто одну ноту |
| `poly3` | дубли после квантования в лад, обход ARPEGGIO |
| `structure` | enum == таблица приложений, группы браузера, иконки, уникальность целей META, все модули звучат со значениями по умолчанию |
| `meta` | MORPH LFO ведёт параметр; экран показывает модулированное значение; индикатор и связь в созвездии |

Заглушки покрывают ровно то, что вызывает прошивка. Два отдельных
стенда однажды разъехались, и половина проверок молча перестала что-то
значить — поэтому стенд теперь один и лежит в репозитории.
